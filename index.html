📖 What these headers mean

  • Sunset
    A date/time after which the resource will no longer be available. Defined in RFC 8594. If you see this, you have until that date to migrate. The closer the date, the more urgent the action.
  • Deprecation
    Signals that the endpoint is deprecated (may be a boolean "true" or a date). Often accompanies a Link header pointing to the replacement.
  • X-Api-Version / Api-Version
    The version of the API that responded. If this changes without your code changing, you may have been automatically upgraded to a newer version.
  • Link
    When paired with rel="deprecation" or rel="successor-version", points to the replacement endpoint or deprecation documentation.
  • Warning
    A general-purpose warning header. Some APIs use this to signal deprecation with a human-readable message (e.g. Warning: 299 - "This endpoint is deprecated")
